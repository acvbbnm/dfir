# 아티팩트와 원본 보존

KAPE Modules가 만든 CSV를 읽어 SQLite에서 조사할 수 있게 했다. 포렌식 기록을 해석한 뒤에도 어떤 파일의 어느 행에서 가져왔는지 확인할 수 있도록 출처와 원본을 같이 저장했다.

## 가져오기

1. 입력 파일을 열거하고 SHA-256을 기록한다.
2. 형식에 맞는 어댑터로 CSV를 읽고 원래 행과 행 번호를 저장한다.
3. 원본을 가리키는 관찰 기록을 만든다. 한 행에 의미가 다른 시각이 여럿 있으면 별도로 표시한다.
4. 같은 경로나 계정을 공유하는 기록은 관계로 연결하고, 연결에 사용한 참조를 남긴다.

C 드라이브와 VSS에서 수집한 기록은 출처를 구분한다. 시간축과 그래프에서는 같은 원본 행을 조회할 수 있다.

## 확인 결과

9월 9일 개발 환경에서 CSV 27개로부터 168,537개 행을 보존했다. 같은 수집본을 다시 가져왔을 때 225개 출처 파일의 변경이 없었고 행이 중복 추가되지 않았다. 파일 목록과 CSV 행 수는 집계 대상이 다르다.
