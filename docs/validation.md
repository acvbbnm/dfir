# 로컬 검증

## 실데이터 가져오기

9월 9일 개발 환경에서 SQLite 무결성 검사와 반복 가져오기를 확인했다. 기존 레코드 값과 출처 해시를 대조하고, 같은 입력을 다시 가져왔을 때 중복이 생기지 않는 것을 확인했다. 당시 수집본의 종류별 결과는 [검증 기록](USAGE.md#이-수집본의-검증-결과)에 남겨뒀다.

## Sysmon 시간축 누락

Sysmon 어댑터로 데이터를 가져온 뒤 일부 이벤트 유형이 기존 시간축에 나타나지 않았다. 저장된 이벤트와 화면의 표시 조건을 따로 확인했다. 정해진 레인에 속하지 않는 유형은 기본 레인에 표시되도록 보완했다.

## 회귀 테스트와 남은 범위

9월 16일 검사 기록에서 Atlas 회귀 테스트 79개가 통과했다. 별도 cloud-lab의 72개 테스트는 로컬 확장 검증에 해당한다. 실제 AWS 배포 확인과 MFT·USN 검색 통합은 개발 기록에서 진행 상태를 확인할 수 있다.
